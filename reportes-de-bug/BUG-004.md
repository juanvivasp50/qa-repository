
# BUG-004 — Bloqueo sin orientación

**Título:** El usuario locked_out_user bloquea perfectamente pero no da ninguna orientación al usuario.

**Severidad:** Media
**Prioridad:** Media

## Precondición
El usuario hizo login con `locked_out_user, está en la pantalla de login y muestra una caja roja con el texto: Epic sadface: Sorry, this user has been locked out.

## Pasos para reproducir
1. Hacer login con `locked_out_user`.

## Resultado esperado
Sale un mensaje en la caja roja orientando al cliente hacia dónde debe dirigirse o a quién debe contactar para saber más sobre la causa de su bloqueo. 

## Resultado actual
Sólo muestra una caja roja con el texto: Epic sadface: Sorry, this user has been locked out, sin orientación ninguna.
