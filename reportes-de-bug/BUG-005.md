# BUG-005 — Zip Code en Checkout

**Título:** El Checkout permite valores en negativo.

**Severidad:** Baja
**Prioridad:** Baja

## Precondición
El usuario "standard_user" agregó artículos al carrito y procedió con el checkout. 

## Pasos para reproducir
1. Ingresar artículos al carrito.
2. Proceder al checkout.
3. Ingresar valores en negativo en el apartado de "Zip Code".

## Resultado esperado
El campo de Zip Code lanza un mensaje de error diciendo que el valor ingresado es inválido, no permitiendo acabar con el proceso de checkout.

## Resultado actual
Permite procesar el checkout sin ningún problema, dejando ingresar un zip code que no existe.
