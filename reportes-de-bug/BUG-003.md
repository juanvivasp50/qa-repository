# BUG-003 — No se puede proceder con el checkout

**Título:** El campo "Last name" no recibe texto.

**Severidad:** Alta
**Prioridad:** Alta

## Precondición
El usuario terminó de agregar artículos al carrito y seleccionó el botón de "Checkout", y está en el formulario para llenar los datos.

## Pasos para reproducir
1. Hacer login con `problem_user`.
2. Agregar artículos al carrito.
3. Entrar al carrito.
4. Seleccionar "Checkout". 
5. Escribir First Name.
6. Escribir Last Name. 

## Resultado esperado
Se llena el formulario exitosamente y permite terminar la compra.

## Resultado actual
En la casilla de Last Name, cuando la seleccionas, escribe en First Name, así que no deja llenar esa casilla, cuando seleccionamos "Continue", aparece el mensaje de error "Error: Last Name is required"
